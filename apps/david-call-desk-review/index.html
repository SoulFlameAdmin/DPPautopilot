What is built and what still needs integration.

DAVID White Call Desk v0.9

Windows currently supports Twilio trial API verification, test calls, call-status checks, call-log synchronization, local company notes, microphone-only recording and browser-dependent captions.

The Vercel URL is a read-only shared design review. To let Mitko view actual worker sessions, a protected authentication layer and shared database must be built.

Suggested access: owner/admin for settings, reviewer for summaries, worker for assigned companies. No unapproved recording or automatic calling.

Settings / Security

Credentials must stay on the server

Never paste Twilio SID/Secret, personal phone numbers or account credentials into the public Vercel page. The previous keys displayed in chat should be revoked.

Production requirements: user authentication, role-based access, encrypted server-side credential storage, signed Twilio callbacks, audit logs and authorization before viewing call data.
